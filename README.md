# Faine Labs — High-Converting SaaS & AI Growth Agency Landing Page

A responsive, high-converting agency landing page for **Faine Labs** built with a **Crimson Red & Deep Black Theme**, interactive AI & SMS workflow simulators, 7 core service showcases, an interactive ROI software consolidation calculator, and a prominent all-in-one pricing tier.

---

## 🎨 Design & Brand Identity

- **Theme Palette**: Crimson Red & Deep Black
  - **Backgrounds**: Deep Black (`#0A0A0A`) with subtle crimson radial glow mesh
  - **Cards & Surfaces**: Dark Zinc (`#121212`) and Elevated Card (`#18181B`) with glassmorphism backdrop blur and subtle red border opacity (`rgba(220, 38, 38, 0.2)`)
  - **Text & Contrast**: Crisp White (`#F8FAFC`) headings, Muted Slate / Zinc (`#94A3B8`) body copy
  - **Primary Actions & Accents**: Crimson Red (`#DC2626`) with glowing hover states (`#EF4444`, `#B91C1C`) and red shadows (`shadow-lg shadow-red-900/40`)

---

## ⚡ Core Features & Interactive Sandboxes

1. **Interactive AI Chatbot Simulator**:
   - Dynamic prompt chips (*"What's in the All-In-One plan?"*, *"Missed Call speed?"*, *"Book a discovery call"*)
   - Keyword recognition engine for instant qualification responses
   - Simulated typing indicators and formatted message rendering

2. **Missed Call Text-Back & SMS Workflow Visualizer**:
   - Step-by-step interactive simulation: Missed call detection -> Sub-3s automated SMS -> Customer reply -> AI booking link -> CRM deal won

3. **Interactive ROI & Software Replacement Calculator**:
   - Dynamic slider for monthly lead volume
   - Software consolidation checklist (CRM, SMS Marketing, AI Chatbots, Review Engines, Funnel Builders, Calendars)
   - Real-time calculations of monthly and annual savings + estimated recovered lead revenue

4. **7 Core Service Cards**:
   - CRM & Pipeline Automation
   - Automated Lead Nurturing
   - AI Chatbots & Conversational Agents
   - Missed Call Text-Back
   - Reputation & Review Management
   - Smart Booking & Calendars
   - Funnel & Website Hosting

5. **Dedicated All-in-One Pricing Tier**:
   - Centralized pricing card showcasing the complete GoHighLevel & AI Automation Suite ($299/mo)
   - Unlimited team seats, 48-hour turnkey deployment, 14-day money-back guarantee

6. **Interactive Modals & Lead Capture**:
   - Strategy call scheduler with time slot selection
   - Quick onboarding intake form with instant toast feedback
   - Collapsible floating AI widget in bottom-right corner

## 🚀 How to Run & Preview

This project is built with zero external build dependencies (pure HTML5, Tailwind CSS via CDN, Lucide Icons, and Vanilla JS).

### Option 1: Direct File Preview
Simply double click `index.html` or open it directly in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (VS Code / Live Server)
If using VS Code, right-click `index.html` and click **"Open with Live Server"**.

### Option 3: Deploy to Production
Can be deployed in seconds with zero configuration to:
- **Cloudflare Pages / Vercel / Netlify / GitHub Pages**: Just connect your repository or drop the folder.
- **GoHighLevel Custom Code**: Embed the HTML/CSS/JS directly into your GoHighLevel Funnel or Website builder.
